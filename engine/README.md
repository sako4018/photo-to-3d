# photo3d-engine

The Python engine of [photo-to-3d](https://github.com/sako4018/photo-to-3d): it turns one photo into a closed, print-ready STL model. See the main README for how to use it. Besides the `photo3d` command it has a local server: `uv run python -m photo3d_engine --token dev --data-dir FOLDER`.
