# 005: Всяка снимка има своя папка

Дата: 09.10.2026 · Статус: прието

## Контекст
Първата версия на командата записваше само един `.stl` на посочено място. Авторът на проекта каза, че не иска "голи файлове": искаше оригиналната снимка и файлът, направен по нея, да са заедно в папка.

## Решение
`photo3d make снимка.jpg` прави `out/<име>/` с `original.<разширение>` (копие без промяна), `<име>_<височина>mm.stl`, `report.txt` и `details/` (изрязана снимка и суров модел). Същата снимка (сравнена по байтове) ползва пак същата папка, а друга снимка със същото име получава `<име>-2`. `--out файл.stl` запазва стария режим с един файл. Логиката е в `layout.py`.

## Последствия
- Нищо не се презаписва без причина, а друга височина дава втори STL в същата папка.
- `out/` е в `.gitignore`. За README картинките се пази копие в `docs/images/`.
- Бъдещият сървър може да ползва същия `layout.py`.
