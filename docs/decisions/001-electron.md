# 001: Прозорецът е на Electron

Дата: 09.10.2026 · Статус: прието

## Контекст
Трябва ни desktop приложение с 3D преглед, печатна плоча и доклад. Първо е само за Mac, но Windows е планиран за по-късно. AI моделът така или иначе е Python, затова изборът на прозорец не е тясното място. Разгледани са Tauri, нативно SwiftUI и Qt (виж `docs/PLAN.md`, 4.1).

## Решение
**Electron + React + TypeScript + three.js.** Python engine-ът върви като отделен процес зад HTTP на `127.0.0.1`. Решението е потвърдено отново, след като Windows беше отложен.

## Последствия
- Един и същ UI и един и същ WebGL (Chromium) на Mac и Windows, затова Windows по-късно не иска ново приложение.
- Пакетът е около 150 MB (оценка от плана).
- SwiftUI би дало по-"Mac" вид, но иска пълен Xcode (над 10 GB, на този компютър има само Command Line Tools), нов език и пренаписване на UI-а за Windows.
- Tauri отпада, защото изисква Rust, а WebKit и WebView2 рендерират 3D различно. Спестеният размер е без значение при PyTorch.
- Още не е написан нито ред от приложението. Решението е на ниво план.
