# 004: Първо само за Mac

Дата: 09.10.2026 · Статус: прието

## Контекст
Първоначалният план беше за Windows и Mac. Машината за разработка е MacBook Pro M1 Pro, на който CUDA не може да се тества. Дали има Windows компютър с NVIDIA за проверка, не е уточнено. Авторът на проекта поиска първо да работи само на Mac.

## Решение
Само macOS на Apple Silicon до v1.0. Windows е първото нещо след v1.0. Подготовката за него остава записана в `docs/PLAN.md`, секция 12. Режимът "много снимки" (Apple Object Capture) влиза във v1.0, защото е само за Mac.

## Последствия
- Няма Windows CI и няма `.exe`. CI е само на `macos-15`: GitHub обяви `macos-14` за остарял, спира напълно на 2 ноември 2026 г.
- Измерванията са от един компютър. На Windows и на по-слаб процесор времената не са известни.
- Кодът е писан крос-платформено (`pathlib`, тестове с кирилица и интервали в пътя), но не е пускан на Windows.
- Windows компютър за проверка ще е нужен чак когато започне Windows версията.
